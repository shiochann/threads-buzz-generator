Step 1 — Install

拡張機能を読み込む

Chromeウェブストアには公開していない「個人用の拡張機能」なので、フォルダを直接読み込む形でインストールします。パソコン操作が苦手でも大丈夫です。下の手順を上から順番にそのまま進めるだけで、5分ほどで完了します。

Threadsバズ投稿ジェネレーター

ver 1.1.0 約106KB Chrome専用
⬇ ZIPをダウンロード

クリックでダウンロードできます

1

ZIPファイルをダウンロード

受け取った threads-buzz-extension.zip をダウンロードフォルダに保存します。

2

展開（解凍）する

ZIPをダブルクリック、または右クリック →「すべて展開」で解凍します。threads-buzz-extension というフォルダが出てきます。

3

拡張機能の管理画面を開く

Chromeのアドレスバーに と入力してEnter。

4

デベロッパーモードをON

画面右上のスイッチを切り替えます。ここをONにしないと次のボタンが出てきません。「開発者」という名前ですが難しい設定ではなく、ウェブストア以外の拡張機能を読み込むために必要なだけの、ただのスイッチです。

5

「パッケージ化されていない拡張機能を読み込む」

先ほど展開した threads-buzz-extension フォルダを選択します（フォルダの中を開く必要はありません。フォルダごと選んでください）。

✅ ツールバーに拡張機能のアイコンが表示されれば完了です。

Step 2 — Connect AI

AIをつなぐ

拡張機能アイコン →「AI連携の設定」から、使いたいAIとAPIキーを登録します。迷ったら無料のGeminiでOKです。

⚠️ 設定画面は STEP 1（APIキー） と STEP 2（ペルソナ作成） の2段構えです。STEP 1だけ終えてもツールはまだ使えません。続けてSTEP 2で、ペルソナ（アカウント）を1つ以上作成・読み込みしてください。両方終わると設定画面の上部に「✅ 初期設定が完了しました」というバナーが出ます。表示されたら、一度その設定画面を閉じてから、ツールバーの拡張機能アイコンを開き直してください。

ログイン後、左側のメニュー（スマホは上部メニュー）にある「Get API key」または「API keys」という項目をクリックします。

「Create API key」をクリック

画面に出てくる「Create API key」ボタンを押します。プロジェクトを選ぶ画面が出た場合は、特にこだわりがなければ一番上の「Default Gemini Project」を選べばOKです（無料枠での個人利用なら、どのプロジェクトを選んでも動作に違いはありません）。

4

発行されたキーをコピー

英数字の文字列（AIza...のような形式）が表示されるので、コピーします。この画面を閉じると再表示できない場合があるので、その場でコピーしておくのが安全です。

5

拡張機能に貼り付けて保存

拡張機能の「AI連携の設定」画面に戻り、プロバイダーでGoogle（Gemini）を選んだ状態で、APIキー欄にペースト→「接続テスト」→「保存」の順に進めば完了です。

⚠️ 最重要：変換の基本思想
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

元投稿は「設計図」。自分の情報は「素材」。
設計図を崩さず、素材を差し込む作業がこのプロンプトのすべて。
自分らしさを出そうとして設計図を崩すのは絶対にNG。
口調・数字・エピソードが豊富でも、元投稿の型が最優先。

【ロック項目（絶対に変えてはいけない）】
・冒頭フックの構文・リズム：構文・句読点・改行位置をそのまま維持する
・箇条書きの数：元投稿が4項目なら4項目。絶対に増減しない
・箇条書きの並び順の論理：「大→小」「原因→結果」などの論理順を維持する
・締めの構文とリズム：「↓」の使い方・余韻の残し方・最終行の文字数感
・対比・煽り・ストーリーの流れ：対比や展開があれば、その流れは崩さない
・1文の長さ感：短文主体なら短文のまま。長文主体なら長文のまま

【スワップ項目（置き換えていい要素）】
・各箇条書きの中身 → 自分のジャンル・事業ネタ
・固有名詞 → 自分のサービス名・商材名など
・数字 → 上記「使える数字リスト」から
・ジャンル用語 → 自分のジャンルに合う言葉に変換

【変換作業のセルフチェック】
□ 冒頭フックの構文・句読点・改行位置は元投稿と同じか
□ 箇条書きの数は元投稿と同じか
□ 締めのリズム・「↓」の使い方は元投稿と同じか
□ 1文の長さ感は元投稿と揃っているか
□ 設計図が崩れていたら書き直す

口調・文体ルール
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

上記プロフィールの「口調・キャラクター」に合わせて書く。
・話し言葉ベース（書き言葉・丁寧すぎる文章はNG）
・「w」を自然に使う（多用しない）
・短文。1文が長くなりすぎない
・飾らない。リアルな感情が出る
・ライター臭・丁寧すぎる文章は絶対NG

━━━━━━━━━━━━━━━━━━━━━━━━━━━━

・誇張表現：「ビビるほど〜」「えぐいことが〜」「マジで〜」「ヤバい」
・命令語尾：「〜しろ」「〜するな」「〜やれ」「〜しといて」

・日常リアル描写：「朝起きたら〜してた」「寝る前に〜した」

FAQ

よくある質問

データはどこに保存されますか？

APIキーやプロフィールは、このChromeにだけ保存されます（chrome.storage.local）。開発者やAnthropicには送信されません。入力内容は、あなたが選んだAIプロバイダーにのみ直接送られます。

Chromeウェブストアには公開されていないの？

はい。これは個人利用のための「未パッケージの拡張機能」です。フォルダを直接読み込む形でのみ使えます。

PDFのアップロードはできますか？

自動読み取りには対応していません。PDFの中身はテキストとしてコピーし、入力欄に貼り付けてください。

読み込み時にエラーが出ます

ZIPファイルのまま読み込もうとしていないか確認してください。「パッケージ化されていない拡張機能を読み込む」は、解凍済みのフォルダを選ぶ必要があります。

複数のSNSアカウントを運用しています。使い分けできますか？

できます。「AI連携の設定」の「🗂 アカウント管理」で、アカウントごとにペルソナを作成・名前をつけて保存でき、ツールを開くときにどのアカウントを使うか選べます。

接続テストで「is no longer available（このモデルは使えません）」と出ます

Googleが無料モデルを入れ替えたときに出るエラーです。エラーメッセージの中に「代わりにこのモデルを使ってください」という案内（例：gemini-3.5-flash-lite）が書かれているので、そのモデル名を設定画面の「モデル名」欄にコピーして入力し、再度「接続テスト」→「保存」してください。
